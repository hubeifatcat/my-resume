# 武渭星简历站后端 · 部署说明

## 功能

- `POST /api/chat`：接收 `{message, conversation_id?, skills?, tools?}`，返回 `{answer, conversation_id, mode}`
- `GET /api/tools`：返回 SKILL / MCP 工具列表，供前端动态加载
- `GET /api/health`：健康检查
- `GET /api/agents`：返回多智能体 Agent 列表
- `GET /api/trace/{conversation_id}`：查询会话轨迹
- `POST /api/auth/register`：注册并返回 JWT
- `POST /api/auth/login`：登录并返回 JWT
- `GET /api/auth/me`：当前用户信息
- `GET /api/conversations`：会话历史列表
- `GET /api/conversations/{id}`：会话详情（消息 + 轨迹）
- `DELETE /api/conversations/{id}`：删除会话

默认使用内置武渭星知识库回答；如需接大模型，在 `.env` 设置：

- `LLM_PROVIDER=ollama`：后端会调服务器/宿主机 Ollama（默认 `http://host.docker.internal:11434`）
- `LLM_PROVIDER=dashscope`：需要填 `DASHSCOPE_API_KEY`
- `LLM_PROVIDER=deepseek`：需要填 `DEEPSEEK_API_KEY`，默认模型 `deepseek-chat`

多智能体默认开启：`MULTI_AGENT_ENABLED=true`，工具执行模式 `TOOL_EXECUTION_MODE=demo`。

用户体系环境变量：

```env
JWT_SECRET=change-me
JWT_EXPIRE_SECONDS=604800
DATABASE_URL=sqlite:////app/data/wuxing.db
```

## 部署步骤（FinalShell）

1. 把 `backend/` 整个目录上传到服务器，例如 `/root/wuxing-backend`。
2. 进入目录并复制环境变量：

```bash
cd /root/wuxing-backend
cp .env.example .env
```

3. 修改 `.env`（需要接大模型时再改，默认 `LLM_PROVIDER=knowledge` 可直接跑）。
4. 构建并启动：

```bash
docker compose up -d --build
```

> SQLite 数据已挂载到 `backend_data` volume，重建容器不会丢用户。

> 注意：`docker-compose.yml` 已接入外部网络 `hermes_hermes-net`，重建容器后 Caddy 仍能通过 `wuxing-backend` 服务名访问；旧版本需手动 `docker network connect hermes_hermes-net wuxing-backend`。

5. 验证：

```bash
curl http://127.0.0.1:8001/api/health
curl -X POST http://127.0.0.1:8001/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"武渭星有什么工作经历？"}'
```

## RAG 向量库（P0 升级）

- 启动后先灌入简历种子数据（只做一次）：

```bash
docker compose exec wuxing-backend python -m app.ingest
```

- `.env` 相关配置：

```env
RAG_ENABLED=true
QDRANT_URL=http://qdrant:6333
EMBEDDING_PROVIDER=keyword
DASHSCOPE_API_KEY=sk-xxx
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
DASHSCOPE_EMBEDDING_MODEL=text-embedding-v4
EMBEDDING_DIM=1024
RAG_TOP_K=5
```

- 流程：问题 → DashScope 向量化 → Qdrant 检索 → 参考资料拼进 system prompt → DeepSeek 回答。
- `EMBEDDING_PROVIDER=keyword`：不用模型，直接关键词检索，开箱即用；改为 `dashscope`/`fastembed` 可切向量检索。

## 接入前端

前端统一在 `react-app/src/config.js` 配置 `API_BASE_URL`，默认：

```js
export const API_BASE_URL =
  import.meta.env.VITE_API_BASE_URL || "https://api.liumingqing.com/wuxing/api/";
```

如需临时切换，可在构建时用 `VITE_API_BASE_URL` 环境变量覆盖：

- 测试环境：`http://服务器IP:8001/api/chat`
- 正式环境（推荐，走 https）：在 Caddy 配置里给当前域名加一个路径反代，例如：

```caddyfile
handle_path /wuxing/* {
    reverse_proxy wuxing-backend:8001
}
```

并保证 `ALLOWED_ORIGINS` 包含你的 GitHub Pages 地址。
